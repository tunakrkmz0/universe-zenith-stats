Data Dragon Görsel Entegrasyonu

Şampiyon ikonlarının, oyuncu profil ikonlarının ve rehber kapaklarının Riot verilerinden üretilme sürecini açıklayan teknik uygulama raporu.

Proje: universe-zenith-stats

Rapor tarihi: 12 Temmuz 2026

Kapsam: Riot API → uygulama veri modeli → Data Dragon CDN → Next.js Image

1. Yönetici özeti

Data Dragon, Riot Games'in League of Legends statik içeriklerini sunduğu CDN servisidir. Uygulama görsel dosyalarını kendi veritabanında veya public klasöründe saklamaz. Riot API'den alınan championName ve profileIconId değerleri, Data Dragon URL şablonlarına yerleştirilerek görseller çalışma anında yüklenir.

Riot API verisi → isim veya ID → Data Dragon URL'si → Next.js Image → kullanıcı arayüzü

Entegrasyon üç kullanım alanına sahiptir:

  1. Son maçlar ve şampiyon havuzundaki küçük şampiyon ikonları.
  2. Oyuncu vitrini ve son arananlar panelindeki profil ikonları.
  3. Kapak görseli girilmemiş şampiyon rehberlerindeki splash görseller.

2. Data Dragon sürüm yönetimi

İkon URL'lerinde kullanılan sürüm, istemciye açık bir ortam değişkeninden okunur. Değer tanımlanmamışsa uygulama 16.13.1 sürümüne geri döner.

components/lol/champion-icon.tsx — satır 5–6

const dataDragonVersion =
  process.env.NEXT_PUBLIC_DDRAGON_VERSION ?? "16.13.1";

components/lol/profile-icon.tsx — satır 5–6

const dataDragonVersion =
  process.env.NEXT_PUBLIC_DDRAGON_VERSION ?? "16.13.1";

İstenirse .env dosyasında aşağıdaki değer tanımlanabilir:

NEXT_PUBLIC_DDRAGON_VERSION=16.13.1
Not: Data Dragon sürümü oyunun güncel yama sürümüyle uyumlu tutulmalıdır. Eski sürümde yeni bir şampiyonun görseli bulunmayabilir.

4. Oyuncu profil ikonlarının oluşturulması

4.1 Profil ikon ID'sinin Riot'tan alınması

Hesap endpoint'i PUUID sağlar. Uygulama bu PUUID ile platforma özel Summoner V4 endpoint'ini çağırır.

lib/riot.ts — satır 145–154

export async function getSummonerByPuuid(params: {
  puuid: string;
  region: LolRegion;
}): Promise<RiotSummonerDto> {
  const puuid = encodeURIComponent(params.puuid);
  const url = `https://${params.region}.api.riotgames.com/lol/summoner/v4/summoners/by-puuid/${puuid}`;

  return riotFetch<RiotSummonerDto>(url);
}

lib/lol-analysis-service.ts — satır 36–46

let profileIconId: number | null = null;

try {
  const summoner = await getSummonerByPuuid({
    puuid: account.puuid,
    region: request.region,
  });
  profileIconId = summoner.profileIconId;
} catch (error) {
  console.warn("RIOT_PROFILE_ICON_FETCH_FAILED:", error);
}

Profil ikonu isteği hata verirse hata yakalanır ve maç analizi devam eder. Bu nedenle görsel servisi, ana analiz akışını bloke etmez.

export function ProfileIcon({
  profileIconId,

          className="object-cover"

            event.currentTarget.style.display = "none";

      )}
    </div>

}

5. Rehber splash görselleri

Admin panelinde bir kapak URL'si girildiyse doğrudan bu URL kullanılır. Kapak yoksa ve içerik kategorisi champion ise yazı başlığının ilk kelimesi şampiyon adı kabul edilir.

components/guides/guides-showcase.tsx — satır 67–81

function getArticleImageUrl(article: GuideShowcaseArticle) {
  if (article.coverImageUrl) {
    return article.coverImageUrl;
  }

  if (article.category === "champion") {
    const championName = article.title.trim().split(/\s+/)[0];

    if (championName) {
      return `https://ddragon.leagueoflegends.com/cdn/img/champion/splash/${encodeURIComponent(championName)}_0.jpg`;
    }
  }

  return null;
}

Aynı davranış rehber detay sayfasında da bulunur:

6. Next.js uzak görsel izni

Next.js Image bileşeni güvenlik ve optimizasyon nedeniyle her uzak alan adından görsel yüklemez. Data Dragon alan adı ve kullanılan yollar açıkça izin listesine eklenmiştir.

next.config.ts — satır 3–22

const nextConfig: NextConfig = {
  images: {
    remotePatterns: [
      {
        protocol: "https",
        hostname: "ddragon.leagueoflegends.com",
        port: "",
        pathname: "/cdn/*/img/profileicon/**",
        search: "",
      },
      {
        protocol: "https",
        hostname: "ddragon.leagueoflegends.com",
        port: "",
        pathname: "/cdn/*/img/champion/**",
        search: "",
      },
    ],
  },
};

Bu yapı profil ikonlarını ve sürümlü şampiyon ikonlarını kapsar. Rehber splash görselleri mevcut kodda standart <img> etiketiyle kullanıldığı için Next.js Image izin kontrolünden geçmez.

8. Değerlendirme ve öneriler

  • Data Dragon sürümü yeni yamalarda düzenli olarak güncellenmelidir.
  • Şampiyon adı URL'ye eklenmeden önce veri kaynağının Riot anahtar formatında olduğu doğrulanmalıdır.
  • Rehber başlığından şampiyon adı tahmin etmek yerine ayrı bir şampiyon anahtarı saklanmalıdır.
  • Splash görselleri de ileride Next.js Image bileşenine taşınarak boyut optimizasyonundan yararlanabilir.
  • Mevcut ilk-harf yedekleri sayesinde CDN hataları sayfa düzenini bozmaz.
  • Profil ikonu isteğinin hata toleranslı olması, görsel problemi yüzünden ana analiz sonucunun kaybolmasını engeller.
